# osu! Web

Браузерная ритм-игра в стиле osu!, написанная на React + TypeScript + Tailwind CSS.

## 🎮 Возможности

- **Импорт карт** из оригинальной osu!:
  - Поддержка `.osu` файлов
  - Поддержка `.osz` архивов (с аудио)
- **Полная механика игры**:
  - Hit circles (обычные круги)
  - Sliders (слайдеры с отслеживанием курсора)
  - Spinners (спиннеры)
- **Система оценки**: 300/100/50/miss, комбо, точность
- **Визуальные эффекты**: частицы, следы, анимации
- **Управление**: клавиши Z/X, мышь, тачскрин

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## 🎯 Как играть

1. Нажмите "Load Demo Map" или импортируйте `.osu`/`.osz` файл
2. Выберите карту в списке
3. **Круги**: нажимайте Z/X или кликайте мышью в момент, когда approach circle совпадает с кругом
4. **Слайдеры**: нажмите на начальную точку, затем **удерживайте кнопку** и ведите курсор за шариком по пути
5. **Спиннеры**: вращайте курсор по кругу

## 🛠 Технологии

- React 18
- TypeScript
- Tailwind CSS
- Vite
- JSZip (для .osz файлов)
- Web Audio API

## 📝 Примечания

- Для полноценного опыта используйте `.osz` файлы (они содержат аудио)
- `.osu` файлы требуют ручного добавления аудиофайлов
- Демо-карта включает сгенерированный звук через Web Audio API
